# Sponsoring Extro

Thank you for considering sponsorship of Extro! As a small, bootstrapped project, your support directly enables us to dedicate more time to building this universal extension framework.

## 🌟 Why Sponsor Extro?

Extro is an open-core project with limited resources but big ambitions. Your sponsorship directly helps us:

- 🚀 Dedicate more development time to the project
- 🧠 Improve AI code generation capabilities
- 📚 Create better documentation and examples
- 🌐 Build initial platform adapters for the community
